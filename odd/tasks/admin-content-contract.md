# Admin integration contract
Reference: admin-content.md S1-S8. English code identifiers; Spanish UI matching Koru.

## Shared module owned by content worker
Exports from `src/modules/content/index.ts`:
- `TextStyle`: fontFamily?, color?, fontSize?:number, fontWeight?:number, textAlign?:'left'|'center'|'right'|'justify', lineHeight?:number, letterSpacing?:number.
- `ImageValue`: src:string, assetId?:string, alt:string, cropX:number, cropY:number, zoom:number, frameShape:'RECTANGLE_HORIZONTAL'|'RECTANGLE_VERTICAL'|'SQUARE'|'OVAL'|'CIRCLE'|'IRREGULAR'|'ORIGINAL', frameRounded:boolean, fitMode:'COVER'|'CONTAIN', frameScale:number, rotation:number.
- `InsertedText`: id:string, afterId:string, content:string, style:TextStyle.
- `ContentDocument`: version:1, texts:Record<string,string>, styles:Record<string,TextStyle>, images:Record<string,ImageValue>, inserted:InsertedText[], deleted:string[].
- `ContentSlot`: id:string, label:string, section:string, area:'landing'|'navbar'|'footer', kind:'text'|'image'|'link', multiline?:boolean, defaultSize?:number. Links editable through text map, validated against unsafe protocols. `contentSlots: ContentSlot[]`; `defaultContent:ContentDocument`.
- `cloneContent(document):ContentDocument`; `validateContent(document:unknown):ContentDocument` throws on invalid content, colors/numbers/URLs.
- `LocalAsset`: id:string,name:string,blob:Blob,width:number,height:number,createdAt:number.
- `loadDraft():Promise<ContentDocument>`; `loadApplied():Promise<ContentDocument>`; `saveDraft(doc):Promise<void>`; `applyContent(doc):Promise<void>` (only local; validate first; transaction); `saveAsset(asset):Promise<void>`; `listAssets():Promise<LocalAsset[]>`.
- Blob src are resolved on load from assetId. Keep binary blobs in IndexedDB, not localStorage. Do not persist blob URLs as durable asset source. Failed writes reject. Apply dispatches local update notification (BroadcastChannel or equivalent) for open public page. Versioned local DB. Never overwrite corrupt stored data silently.
- `optimizeImageForUpload(file:File):Promise<File>`: Koru behavior, accepted jpeg/png/webp/avif, max dimension2400, quality cascade .84,.72,.6,.5 max10MB; reject unexpected output MIME and decoding errors. UI creates LocalAsset with optimized dimensions.

## Renderer and preview owned by content worker
- `src/modules/content/site-page.tsx` exports `SitePage({content,editing?,selectedId?,onSelect?})`, shared by public home and preview. Default styling unchanged. Text styles applied per slot; images support all ImageValue adjustments. No markup HTML injection, preserve title emphasis via distinct text slots. Every text and image incl logos and nav/footer editable. Extra inserted texts after an anchor and deleted IDs supported. Editing selection uses data-content-id; ignore links when editing. Original page server rendering preserved via default content + client applied-content hydration wrapper.
- `/admin/preview`: iframe standalone page renders SitePage, inherits public styles only. Strict same-origin messages accepted only from window.parent. On ready send `{type:'lisi-preview-ready'}`; on selection `{type:'lisi-select',id}`; on overflow change `{type:'lisi-overflow',ids:string[]}`; on drag in adjusting image mode `{type:'lisi-image-position',id,cropX,cropY}`. Incoming `{type:'lisi-content',content:ContentDocument,selectedId?:string,adjustingImageId?:string}`. All postMessage use exact window.location.origin. No storage writes in iframe. Preview refresh/request responds ready so parent resends. Image drag updates local preview immediately then emits position on release. On load/update/resize measure overflow from data-content-id elements after fonts/images settle.

## UI worker surfaces
`src/modules/admin/**`, `src/app/admin/page.tsx`, `src/app/admin/admin.css`. Parent installs shadcn UI dependencies under src/components/ui and package files, worker may read not modify those. UI worker imports shared module above; no need await content worker's files. Imports may temporarily fail during parallel work. No layout.tsx at admin root because preview must stay standalone.
UI reconstructs Koru using reference paths (authorized read only) but retains exact arrangement and controls; no layout editor. Scope theme vars at .admin-app; never overwrite public :root. Theme persisted via localStorage separate from content. Native IDB used through shared API. UI load errors must not allow overwriting failed/corrupt drafts, disabled apply until loaded, status explicit. Save draft content with debounce+serialized queue and flush on apply. Status of previous save must not incorrectly mark newer edits as saved. Koru selector prev/next count, 320px right panel, content/device toolbar, desktop sidebar, mobile panels with shadcn Sheet. UI custom upload validates through optimizer before storing; failed upload retains old image; library supports existing and uploaded assets. Apply explicit local-only; preview badges warn no auth. Text styles full set and inserted block controls (add/move/delete), link editing safe. Image UI full Koru controls including zoom, shape, borders, crop/full,scale,90 rotation, adjust/center, alt. Device widths1440,768,390,375,320. Keyboard accessible controls. Revoke per-component library object URLs on unmount, never before document stops using them.

## Tests
Node test runner via node --experimental-strip-types --test (check installed Node support). Unit public APIs: catalog/default validation, storage persistence/failure with injected IDB factory or fake-indexeddb if parent installs, image conversion using browser API stubs for RED/GREEN. Parent adds npm test scripts. Browser checks via Playwright if available, else clearly unavailable. Workers write tests under tests/content/ and tests/admin/ respectively. Capture RED before implementation and GREEN after. Do not commit.
